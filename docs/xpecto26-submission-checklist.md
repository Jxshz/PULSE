# Xpecto'26 Submission Checklist

Based on `Detailed Submission Instructions - Xpecto'26.pdf` dated April 23, 2026.

## Form Fields

- Name
- College
- Phone Number
- Project Title
- Folder Upload
- YouTube Video Link

## Required Upload Package

Create a zip file named `IITMD_name.zip` containing:

- A presentation explaining the problem statement and workflow design
- The dataset used for training and testing
- The RapidMiner `.rmp` workflow file

## Delivery Notes

- Upload the zip contents to Google Drive
- Share the folder with "Anyone with the link"
- Submit the drive link in the Google Form
- Record a demo video explaining the data science or machine learning workflow
- Upload the video to YouTube
- Keep the video public or unlisted
